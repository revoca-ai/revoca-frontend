Landing Page Layout Approach

Which one-pager structure feels most impactful for Revoca AI?

A

Hero-Centric Flow

Structure: Full-screen hero with bold tagline + animated context graph visual → Problem/Solution section → Connector icons strip → Discord bot showcase → CTA (Book a Call)

Feel: Big dramatic opening, scrolls through story. Like Linear or Vercel's landing pages. Hero takes 100vh, rest flows naturally.

Pros

  • Maximum first-impression impact
  • Clean storytelling arc
  • Easy to build

Cons

  • Less info above the fold
  • Relies on user scrolling
B

Split Hero + Product Preview

Structure: Left: tagline + CTA + connector icons. Right: animated mockup of Discord bot in action → Feature cards (3 pillars: Onboarding, Support, Never OOO) → How it works diagram → CTA

Feel: Shows the product immediately. Like Notion or Slack's approach. More info-dense above the fold.

Pros

  • Product visible immediately
  • More content above fold
  • Connectors visible early

Cons

  • Slightly busier
  • More complex to execute well
C

Cinematic Scroll

Structure: Full-screen sections that snap-scroll: Hero → Problem ("Your devs go offline. Context dies.") → Solution ("Revoca keeps them present.") → Connectors → Discord bot → CTA

Feel: Each section is a full viewport. Dramatic, Apple-keynote style. Scroll-triggered animations.

Pros

  • Most dramatic/memorable
  • Forces focus per section
  • Great for storytelling

Cons

  • Heavier to build (animations)
  • Can feel slow on mobile
  • Snap-scroll can annoy some users
